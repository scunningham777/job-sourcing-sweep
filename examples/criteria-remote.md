# Job search criteria – remote senior front-end

Screening reads this whole file and judges every lead against it. Write it the way you'd brief a
friend who's helping you search: hard rules first, then what makes a role stand out.

## Hard filters (exclude if failed)

1. **Fully remote within the US.** No hybrid or regular in-office expectations.
2. **Base salary ≥ $140K.** If a posted range is wide, at least the top half must clear it.
3. **Front-end-leaning.** Exclude roles whose core requirement is backend, infrastructure, or
   data engineering depth.
4. **Reasonably stable company.** Avoid obvious near-term instability (just acquired, layoffs,
   stale or unclear funding with nothing to offset it).

## Positive signals (not required, but count in favor)

- Senior or Staff-level individual-contributor role
- TypeScript and React named in the core stack
- Strong disclosed benefits
- Sane working expectations – flag postings that read as "always on"

## Notes

- If salary isn't posted, keep the lead as a candidate and say to confirm pay before applying.
